# Changelog

## [2.3.1]

- Smooth the edges of small numbers and units in the taskbar widget.
- Keep the widget visible when interacting with the taskbar.

## [2.3.0]

- Choose English or Persian in Display settings. NetBar remembers the selected language and switches the settings layout between left-to-right and right-to-left.
- Translate the system tray menu to match the saved language.

## [2.2.1]

- Check for and install updates from public GitHub Releases without signing in.
- Show the public release source in Settings.
- Distribute NetBar under the MIT License and include the license in new MSI installations.
- Publish a SHA-256 checksum alongside each Windows installer.

## [2.2.0]

- Draw the taskbar widget in a cached native Windows bitmap. WebView2 opens with Settings and exits when the window closes.
- Right-click the widget to pause or resume readings.
- Use regular text, evenly spaced Feather icons, and aligned speed units.

## [2.1.1]

- Remove hover details from the taskbar widget.
- Use Feather arrows for upload and download.

## [2.1.0]

- Redesign Settings and the taskbar widget with Tauri.
- Introduce a new application icon.

## [2.0.0]

- Rewrite NetBar in Rust and preserve upgrades from the original Windows installer.
- Add update checking and verified MSI installation in Settings.
