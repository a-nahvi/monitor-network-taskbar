# Security

Use [Report a vulnerability](https://github.com/a-nahvi/monitor-network-taskbar/security/advisories/new) to report a security issue privately on GitHub. Include the NetBar version, Windows build, steps to reproduce, and likely impact. Remove credentials and personal information from attachments.

Test the issue against the latest release when possible. Use [GitHub Issues](https://github.com/a-nahvi/monitor-network-taskbar/issues) for ordinary bugs and feature requests.
